# VLCoT 研究实现

[论文主页](https://apromisedland.github.io/vlcot-paper-page/) · [英文文档与命令](README.md)

本仓库依据论文实现阶段潜在推理、观测验证、依赖感知后缀修复，以及训练和评测工具链。包含真实 OpenVLA-7B 适配器、连续动作头、离线标签处理、LoRA 微调、LIBERO/RoboTwin 环境接入、预算计费和受控消融。

**当前状态：**原始实验代码、VLCoT 权重、阶段标注及逐回合记录未随论文提供。本实现补全了论文未明确的结构和设置，详见 [方法对应说明](docs/METHOD.md)。本次发布未运行训练、推理、仿真、测试或 CI，论文报告的数值不是此代码的实测结果。

## 使用顺序

1. 在 Linux GPU 主机建立独立 Python 环境，安装 `.[model,dev]`。模拟器按各自版本单独准备。不要把依赖安装到共享应用运行时，也不依赖 shell 激活。
2. 准备合法可用的 OpenVLA 本地文件、机器人示范和任务标注配置。默认禁止模型自动下载。
3. 用 `prepare-data` 转换 HDF5 轨迹；已有谓词和可观测性标签可直接使用，否则 LIBERO 可用 `replay-labels` 离线回放获取。
4. 用 `annotate` 提取稳定事件边界及阶段前提/效果，再用 `make-config` 绑定实际谓词顺序、相机和动作维度。
5. 用 `train` 明确指定训练步数、配置和输出目录。训练集、验证集与测试集按来源轨迹和失败场景分组；动作归一化只读取训练集。
6. 用 `evaluate` 输入固定评测清单、模型检查点、预算和成本表；`summarize` 从真实回合记录汇总，`diagnose` 独立评估固定观测集的阶段验证 F1。

完整命令见英文 README。[数据规范](docs/DATA.md) 说明原始字段映射、标注契约和可观测性标签，[评测规范](docs/EVALUATION.md) 说明正式协议清单与统计定义。

## 与论文的关系

- 保留每阶段四向量、窗口八阶段、预测八步执行四步、三次连续确认、AdamW、LoRA rank 32 等已记录设置。
- 用连续隐状态回灌生成潜在阶段；阶段解码器和独立观测估计器分别给出预期与证据。模拟器真值只用于离线标注及独立评分。
- 证据不足不推进阶段；正常中间运动不立即触发修复。持续偏差触发必要条件检查，从最早受影响阶段开始重建。
- 保留有效潜在前缀，清除失效阶段的历史信息。合法释放不会要求重新抓取；跨规划窗口仍能回溯历史依赖。
- 依赖预测头、终止头、观测窗口和阈值初值、事件契约、动作头结构、工作量计费单位属于公开说明的工程选择，需要后续训练与校准。
- LIBERO-RECOVER 正式失败实例与 RoboTwin 十任务协议清单需外部提供；不以其他扰动实验或任意子集代替。

## 验证和发布边界

本轮只编写并静态审阅代码。测试文件提供核心状态机、统计口径、梯度、检查点和前缀保留的检查入口；小模型测试不等同于真实 OpenVLA 验证。Actions 仅支持手动触发，不会因推送自动运行。

冻结的 OpenVLA 权重、数据和运行输出不进入 Git。新写代码采用 MIT；论文、外部数据和模型依然遵循各自条款。
