# Paper-to-code mapping and engineering choices

The canonical source is the 13-page author-supplied ICML manuscript linked from the [paper page](https://apromisedland.github.io/vlcot-paper-page/). The repository implements its equations and module interfaces, with explicit choices where the source does not identify architecture, calibration, data, or optimizer duration. No numerical equivalence with the original experiments has been established.

## Representation and gradients

| Paper mechanism | Implementation |
| --- | --- |
| Eq. 1: encode instruction, observations, verified history | Frozen OpenVLA vision/projector, trainable view/proprio/history projections, causal language backbone with LoRA |
| Stage latent `Z_i` with four hidden-size vectors | Autoregressive hidden-state feedback with a learned start vector and within-stage slot embeddings |
| Eq. 3: expected endpoint and observed state | Separate `StageDecoder` and `ObservationEstimator` modules |
| Eq. 4: masked stage alignment | Predicate BCE normalized within each valid stage, then averaged over valid stages in the sampled window |
| Eq. 5: imitation + stage + observation objectives | Masked continuous L1, stage BCE, observation BCE; auxiliary structural/visibility supervision reported separately |
| Eq. 6: observation-grounded discrepancy | Confidence-weighted absolute probability difference, required-predicate evidence checks, consecutive confirmation |
| Eq. 7: earliest affected suffix | Historical predicate ownership and future prerequisite checks, retained prefix, conditional regeneration |
| Eq. 8: full task-level cost | Disjoint encoding/planning/extension/verification/action/repair ledger |

Latent generation calls the stock causal Llama decoder. Generated continuous states feed subsequent decoder inputs. Stage outputs are differentiable during training; inference stopping uses a learned stage-level sigmoid. Action queries attend to the latest contextualized observation and the active/remaining latent vectors, followed by two residual MLP blocks and bounded continuous regression.

This action head is an engineering implementation of continuous chunking with L1, not a claim to reproduce OFT's exact action architecture. OFT's global bidirectional-attention fork is deliberately not used for autoregressive stage generation. The stock Transformer performs causal latent reasoning; the separate action head reads all available context and remaining latents in parallel.

The state estimator cross-attends predicate queries to the recent encoded images, language tokens, and proprioception with temporal embeddings. It has no latent, stage prediction, historical ground-truth state, or simulator-state input. Shared image features are cached once for each observed decision frame. Its state probability certainty is combined conservatively with predicted observability using a minimum.

## Additional supervision

The manuscript does not specify how stage dependencies or termination positions are parameterized. This implementation adds stage heads for:

- endpoint predicate probabilities;
- relevance/effect masks;
- required-condition masks and desired values;
- relations released by the stage;
- stopping the current planning window.

Task-specific event contracts provide these labels from offline demonstration events. A release expires an earlier established relation; an explicit new effect may establish a new value for the same predicate. This supports legitimate release after placement without redoing a completed grasp.

The observation estimator also predicts visibility. Simulator truth alone does not establish that a relation is visually observable. Imported visibility labels have independent validity masks. The optional replay path offers an explicitly named `all_objects_visible_proxy`, based on simulator segmentation only during offline labeling. This proxy is a visibility heuristic, not proof that a relation can be visually inferred; calibrate it or replace it with independently audited labels. Missing visibility supervision remains unknown, and the trainer refuses an entirely unsupervised observation head.

Prefix/suffix training samples either a stage boundary or a random trajectory frame. The prefix is generated in rolling windows, starting from the episode's initial observation and then using the corresponding demonstration boundary observations and verified history. The suffix is generated from the current observation and validated demonstration history. Latent vectors themselves are generated by the model, not copied from privileged labels. Action targets start at the sampled observation and use masks at trajectory tails. Variable prefix/suffix lengths are processed as per-example graphs; microbatches are averaged and accumulated.

The `base` variant uses only action supervision; `auxiliary` predicts stage endpoint labels from the current context without a latent chain and also trains observation estimation. `no_alignment` detaches the latent input to all stage semantic heads while preserving decoder updates and action gradients. A full trained checkpoint with `--strategy disabled` is the preferred matched-weight repair-disabled comparison. `--variant no_repair` is also available for training the same architecture; it must not be represented as the shared-weight comparison unless its checkpoint is actually shared.

## Execution invariants

The verifier requires all relevant predicates to be sufficiently observed and all supported discrepancies to be below threshold. A negligible weight sum, absent relevant predicates, or hidden required historical conditions leaves the stage unconfirmed. A single observation cannot be counted repeatedly. Missing evidence resets confirmation and stagnation persistence.

Normal motion can differ from the endpoint. Stagnation is tracked only under reliable evidence and requires repeated failure to improve the best discrepancy. Historical prerequisite violations use a separate persistence counter and may expand repair to a stage in an earlier planning window. When a future stage will overwrite or release a predicate before it is needed, an obsolete historical value is not kept as a prerequisite.

After repair, invalidated history entries are removed and the verifier is reset. Local repair preserves the prefix tensors exactly. `current` retains the latent prefix but cannot regenerate an invalid earlier stage; contradicted history is still removed from the context. `full` regenerates the remaining plan without conditioning on retained latent vectors, while retaining valid completed history. It does not physically replay completed actions. `disabled` continues observation/action execution without deviation-triggered generation.

Rolling extension appends a new window when the active window is complete. It never certifies physical success. The environment independently scores success. The entire retained latent history remains addressable for earlier prerequisites; exceeding the configured context limit is an explicit error rather than silent truncation. No Transformer KV cache is reused across changed observations. The implementation does not claim hardware savings from KV reuse.

All configuration and normalizer metadata travel with each checkpoint. Conditional suffix training uses the same data policy as the selected experiment; recovery trajectories and dedicated initial-frame input are disabled by default and studied separately.

## Validation status

Source syntax and repository content may be statically inspected without importing the project. The supplied tests have not been executed for the initial release. Neither CPU tiny-model tests nor source review establish real OpenVLA compatibility, trained performance, simulator integration, or the paper's reported efficiency. Those require subsequent explicit runs on the intended environments and datasets.
